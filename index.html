PROBLEM SETUP
01 · The Problem
03 / 13

The dashboards we have actually mislead us.

Plot cost-per-result vs spend — the standard chart — and the dots form pretty curves that look like performance patterns. They are not. They are mathematical artifacts of plotting spend ÷ N against spend. Each "curve" is just one fixed integer payment count.

PROBLEM
02 · The Maths Behind It
04 / 13

Act on belief, not observation.

A creative's observed CAC at low N is noisy. The Poisson upper-confidence interval narrows as payments accumulate. Kill only when the posterior belief — not the noisy observation — clears the threshold with 95% confidence.

Posterior = Prior × Likelihood
↓ updated every 6 hours ↓
P(true CAC > ₹802 | data) ≥ 0.95 → KILL
The same math a trading desk uses for stop-loss orders — applied to ad spend.

02 · Bayesian Sequential
05 / 13

Bayesian sequential — belief tightens with every tick.

Bayesian sequential testing updates the posterior belief about a creative's true CAC every 6 hours as new data arrives. Stop the moment confidence crosses 95% — for either kill OR futility. No fixed windows. No waiting two weeks for an A/B test to "complete."

03 · Proposed Solution
11 / 13

So how do we actually ship this?

Phase 1 is the minimal viable kill switch. Python script + Slack delivery + manual execution. Built with Claude in 4-5 days. No engineering team. No infrastructure procurement. Captures 60% of that 100× year-1 ROI before any automation kicks in.

DAY 1

Data Pipeline

Pull campaign data from Zivon daily. Compute m, fatigue, kill ladder per campaign.

~4 hours
DAY 2

Decision Engine

Kill ladder logic (Poisson 95% CI). Tag KILL / SCALE / MAINTAIN / OBSERVE with reasoning.

~3 hours
DAY 3

Slack Delivery

Daily 9am message: kill list, scale candidates, anomaly flags — scannable in 30 seconds.

~2 hours
DAY 4

Execution Log

CSV / sheet tracking what was executed, skipped, overridden — training data for Phase 2.

~2 hours
DAY 5

Calibration

Run live. Walk through with one campaign owner. Refine. Ship to all owners by EOD.

~1 day

What it does NOT include

Six-agent architecture · auto-execution · A/B testing framework · Memory Agent · cross-platform Google Ads. All deferred to later phases — see roadmap.

What you get on Day 5

An honest daily kill list backed by 95% Poisson confidence intervals, surfacing the RT - Camp class of disasters before they happen again.
